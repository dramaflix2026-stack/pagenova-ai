# blueprints

Composições prontas de página: a ordem de seções e as variantes que costumam
funcionar juntas para um objetivo (agendamento, orçamento, autoridade).

Vazio de propósito. Hoje a composição é decidida pela IA a cada geração; um
blueprint vira o ponto de partida dela e o atalho do editor.

Um blueprint é dado, não código: lista de `{ type, variant }` validada contra
o registry, sem HTML.
