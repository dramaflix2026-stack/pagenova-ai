# Licenças

Registro do que veio de fora e sob qual licença: fontes, ícones, bibliotecas,
trechos de código e imagens.

Um arquivo por item, nomeado pelo que descreve (`fontes-google.md`,
`icones-lucide.md`). Cada um responde: o que é, de onde veio (URL), qual a
licença, a data da verificação e onde é usado no produto.

O processo está em `.claude/rules/site-kit.md`, seção 11.
